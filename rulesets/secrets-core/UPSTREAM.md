## Translation

- Each rule becomes one YARA-X rule named after the gitleaks id with `-` replaced by `_` (and `_` prepended to an id starting with a digit).
- Regexes are read with Go (RE2) syntax: a `{` that does not start a repetition is escaped for Rust and YARA-X; nothing else changes.
- The regex is the anchor `$re`, with lazy quantifiers rewritten as greedy (YARA-X refuses mixed greediness). The original regex is kept as `span_regex`; the `span` post-processor re-runs it inside each match to find the secret (`secretGroup`, else the first capture group, else the whole match).
- Keywords are `nocase` literals `$kw0..n`; the rule needs one of them and `$re`.
- `entropy` becomes the `entropy` post-processor on the secret. gitleaks drops a secret whose entropy is at most the threshold; the post-processor drops one below it.
- Allowlist stopwords become `stopwords/secrets_core_<rule>.txt` (rule and global stopwords) or `stopwords/secrets_core_global.txt` (global only).
- Allowlist regexes that target the secret become one `allow_regex` alternation (rule and global regexes).
- Allowlist paths become `not path matches` conditions; the global ones are the private rule `gitleaks_global_path_allowlist`.
- A rule `path` becomes a `path matches` condition; a rule with only a path yields one evidence item.
- A regex that would match its own rule text has its last literal letter or digit wrapped in a one-character class (`abc` becomes `ab[c]`), in both `$re` and `span_regex`. It matches the same secrets, and the shipped ruleset does not report itself.
  Rewritten: `aws-amazon-bedrock-api-key-short-lived`.

## Weights

- fixed provider prefix (95): 121 rules.
- private key (95): 2 rules.
- provider context (80): 98 rules.
- local change (see below): `generic-api-key` (80).

A rule is "fixed provider prefix" when every match of its secret starts with a literal of at least 3 bytes (for example `ghp_`). `private-key` and `pkcs12-file` are private keys; ids starting `generic` are generic; the rest are "provider context" (a provider name near a value). `pkcs12-file` is in family `pkcs12` with cap 90, shared with `pkcs12_keystore` in `keystores.yar`.
